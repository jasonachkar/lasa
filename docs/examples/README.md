# Scanner output examples

[Documentation home](../../README.md)

[unsafe-permissions.json](unsafe-permissions.json) is an extracted finding/evidence fragment produced by the real scanner against a deliberately writable isolated fixture named `sudoers`. It demonstrates explanation, prerequisites, uncertainty, score contributions and provenance. It is not a full report and must not be submitted as `lasa.report/v1` input. It does not claim a real host's active sudoers file was vulnerable.

Real restricted-host scan totals, commands and partial-coverage interpretation appear in the [verification record](../maintainer/verification.md). Full infrastructure reports are deliberately not committed as examples because they can expose service and identity metadata.
